# 政务公开信息整合平台 PRD（原型版）

## 1. 产品概述
- 目标：整合各政府官方网站的政务公开信息，为公众与媒体提供统一检索、浏览与引用的入口。
- 价值：提升信息获取效率与透明度，降低跨站点查找成本，支持信源溯源。
- 数据来源：已有爬虫产出数据（参考 `d:\gov.scrapy\项目文档.md`）。

## 2. 用户与角色
- 访客用户：浏览、搜索、筛选、查看详情、复制链接、下载附件。
- 管理员：数据审核（去重、合并、状态标记）、来源管理、任务监控、手动修正。

## 3. 核心用例（MVP）
- 浏览最新/热门政务信息列表。
- 搜索关键词（标题、正文），支持时间范围与来源单位筛选。
- 查看信息详情（标题、来源单位、发布日期、正文、附件、原文链接）。
- 管理员审核与标注信息的有效性与分类。

## 4. 页面与信息架构
- 首页：搜索框、分类快捷入口、近期更新、来源单位概览。
- 列表页：分页、排序（时间/相关度）、筛选（来源、时间段、分类、地区）。
- 详情页：正文渲染、附件下载、原文链接、元数据（来源、采集时间、数据ID）。
- 搜索页：关键词输入、高级筛选、结果列表。
- 后台管理：登录、来源管理、数据审核队列、任务监控（只做最小可用）。

## 5. 标准化数据字段（建议）
- `id`，`title`，`source_org`，`source_url`，`publish_date`，`content_text`，`content_html`
- `attachments[]`（名称、URL、文件类型、大小）、`categories[]`、`tags[]`
- `region`（省/市/区），`crawler_job_id`，`status`（draft/published/invalid/archived）

## 6. MVP 范围与非目标
- 范围：访客浏览/搜索/筛选/详情；管理员审核（基础）；统计基础搜索日志。
- 非目标：复杂权限、深度分析报表、移动端适配、复杂工作流（后续迭代）。

## 7. 成功指标（原型）
- 首周访问量、搜索次数、点击详情率、数据覆盖量（来源、地区、时间段）。
- 性能：列表查询 ≤ 500ms；首屏渲染 ≤ 2s（CDN缓存与分页）。

## 8. 路线图
- 里程碑 M0（1-2 周）：原型上线（浏览/搜索/详情/基础审核）。
- 里程碑 M1：后台完善（来源管理、批量审核、日志报表）。
- 里程碑 M2：搜索优化（同义词、模糊匹配）、分析看板。
