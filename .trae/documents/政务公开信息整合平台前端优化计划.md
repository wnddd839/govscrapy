#### **1. 接口配置更新（`src/api/publicInfo.js`）**

**javascript**

运行

```
import axios from 'axios'

// 创建请求实例，统一配置
const service = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL, // 从环境变量读取基础地址
  timeout: 5000
})

// 统一响应拦截器（适配后端ApiResponse格式）
service.interceptors.response.use(
  response => {
    const res = response.data
    if (res.code !== 200) {
      // 统一错误提示（使用Element Plus的ElMessage）
      ElMessage.error(res.msg || '请求失败，请重试')
      return Promise.reject(res)
    }
    return res.data
  },
  error => {
    ElMessage.error('网络错误，请检查连接')
    return Promise.reject(error)
  }
)

// 政务信息核心API
export const publicInfoApi = {
  // 1. 获取所有分类标签（动态加载）
  getCategoryList: () => service.get('/api/gov/category/list'),
  
  // 2. 获取热门数据（最新20条）
  getHotList: () => service.get('/api/gov/hot/list'),
  
  // 3. 获取分类数据（分页）
  getCategoryData: (params) => service.get('/api/gov/category/data', { params }),
  
  // 4. 获取信息详情
  getDetail: (dataId) => service.get(`/api/gov/detail?dataId=${dataId}`)
}

export default publicInfoApi

```

/**
 * 格式化时间：YYYY-MM-DD HH:mm:ss → YYYY-MM-DD 或 保留完整格式
 * @param {String} timeStr - 原始时间字符串
 * @returns {String} 格式化后的时间
 */
export const formatTime = (timeStr) => {
  if (!timeStr) return ''
  // 若包含时分秒，可选择保留或截取日期部分
  return timeStr.includes(' ') ? timeStr.split(' ')[0] : timeStr
}

  router.push({

    query: { dataId: row.dataId }
  })
}

## **三、关键技术要点总结**

1. **接口适配**：严格按照后端标准化接口格式调整，统一响应拦截器处理；
2. **动态分类**：从 API 获取分类标签，支持后端配置扩展，无需修改前端代码；
3. **数据映射**：前端字段与后端`PublicInfo`实体类对齐（如`dataId`、`publishTime`、`category`等）；
4. **分页逻辑**：基于后端分页接口，实现页码、每页条数动态调整；
5. **体验优化**：统一加载状态、空状态、错误状态，添加刷新功能，提升用户体验；
6. **响应式适配**：页面布局支持 PC / 平板端，表格、列表自适应宽度。

## **四、测试与联调要点**

1. 接口联调：确保`/api/gov/category/list`、`/api/gov/hot/list`等接口返回格式符合预期；
2. 分类一致性：验证前端分类标签与后端`gov_category_config`表完全一致；
3. 数据流转：测试爬虫写入 Redis→后端同步 MySQL→前端展示的全链路数据正确性；
4. 异常场景：测试接口请求失败、无数据、Redis/MySQL 故障等场景的前端适配；
5. 性能测试：验证热门数据（Redis）、分类数据（MySQL）的加载速度，确保分页流畅。

通过以上优化，前端将完全符合政务公开信息整合平台的整体方案设计，实现分类动态化、数据精准化、体验流畅化的核心目标。
