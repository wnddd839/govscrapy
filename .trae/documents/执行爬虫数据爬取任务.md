# 执行爬虫数据爬取任务

## 1. 爬虫选择

选择 `config_based_spider`，理由：

* 基于配置的动态爬虫，支持多网站爬取

* 从 `crawl_rules.yml` 加载多个网站的爬取规则

* 支持自动分类标记

* 完善的反爬策略

* 严格遵循后端Redis存储规范

## 2. 执行步骤

1. **检查爬虫状态**：已确认爬虫列表中存在 `config_based_spider`
2. **执行爬取命令**：运行 `python -m scrapy crawl config_based_spider`
3. **监控爬取过程**：查看日志输出，确认爬取进度和数据写入情况
4. **验证数据写入**：检查Redis中是否有数据写入

## 3. 预期结果

* 爬虫成功启动，开始爬取配置的网站

* 数据按后端规范写入Redis

* 日志中显示成功写入Redis的信息

* Redis中生成Hash和Sorted Set结构

## 4. 后续验证

* 检查Redis中的Hash数据：`gov:data:{dataId}`

* 检查待同步集合：`gov:data:new`

* 检查热门数据集合：`gov:data:hot`
