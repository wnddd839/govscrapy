### 问题 5: 附件数据缺失 (Attachments Missing) - **新发现**
- **现象**: 详情页接口 `/public-info/detail/data/{id}` 返回的 `attachments` 字段为空数组 `[]`。
- **证据**: 用户提供的 Network 截图显示 `attachments: []`。
- **影响**: 前端无法展示附件下载和预览区域。
- **可能原因**: 
    1. 数据库中该记录确实无附件。
    2. 后端 MinIO 路径检测逻辑未命中。
    3. 后端实体映射未将数据库字段正确映射到 `attachments`。
