# 爬虫支持需求文档

## 1. 概述

本文档定义了爬虫需要支持的分类标记功能需求，确保爬虫在爬取政务信息时能正确标记分类字段，为前端分类查询提供数据支持。

## 2. 分类体系

### 2.1 分类列表

爬虫需要支持以下分类体系，与前端页面的分类保持一致：

| 分类名称 | 描述 | 示例内容 |
|----------|------|----------|
| 政策法规 | 政府发布的政策、法规、办法、规定等 | 关于印发《2024年工作计划》的通知、XX省人民政府令 |
| 人事信息 | 人事任免、人员公示、处分决定等 | XX同志任职通知、XX市事业单位公开招聘拟聘人员公示 |
| 规划计划 | 政府规划、发展计划、纲要等 | XX市2024-2030年城市发展规划、XX省2024年工作计划 |
| 公考资讯 | 公务员考试、事业单位招聘、资格审查等 | XX省2024年公务员考试公告、XX市事业单位招聘简章 |
| 招标采购 | 招标公告、中标结果、采购信息等 | XX项目公开招标公告、XX采购项目中标公示 |

### 2.2 分类扩展

- 支持新增分类，需与前端页面同步更新
- 分类名称变更时，需同步更新数据库中的历史数据

## 3. 分类标记逻辑

### 3.1 基于爬取来源的标记

爬虫应根据数据的爬取来源（如网站栏目、频道）直接标记分类：

| 爬取来源示例 | 对应分类 |
|--------------|----------|
| 政策法规频道 | 政策法规 |
| 人事任免栏目 | 人事信息 |
| 发展规划栏目 | 规划计划 |
| 公务员考试频道 | 公考资讯 |
| 招标采购栏目 | 招标采购 |

### 3.2 基于内容的辅助标记

对于无法直接从来源判断分类的数据，可采用以下辅助标记逻辑：

1. **关键词匹配**：
   - 政策法规：包含"办法"、"规定"、"条例"、"法律"、"法规"、"决定"、"意见"、"措施"、"细则"等关键词
   - 人事信息：包含"撤职"、"任免"、"名单"、"公示"、"人员"、"处分"、"免去"、"任命"等关键词
   - 规划计划：包含"规划"、"计划"、"纲要"、"方案"、"年度计划"、"发展规划"、"专项规划"等关键词
   - 公考资讯：包含"录用"、"招聘"、"考试"、"岗位"、"公考"、"面试"、"成绩"、"拟聘用"、"资格审查"、"报名"等关键词
   - 招标采购：包含"招标"、"采购"、"中标"、"成交"、"单一来源"、"竞争性磋商"、"询价"等关键词

2. **标题分析**：优先分析标题内容进行分类判断

3. **正文辅助**：结合正文内容进行辅助判断

### 3.3 分类优先级

分类标记的优先级顺序：
1. 基于爬取来源的直接标记（最高优先级）
2. 基于标题关键词的标记
3. 基于正文关键词的标记
4. 人工干预标记（最低优先级）

## 4. 数据存储要求

### 4.1 字段存储

- 将分类信息存储到数据库的`category`字段中
- 分类名称必须与前端页面的分类名称完全一致
- 不允许存储无效或不存在的分类名称

### 4.2 数据格式

| 字段名 | 数据类型 | 格式要求 | 示例值 |
|--------|----------|----------|--------|
| `category` | VARCHAR | 中文，与分类列表完全匹配 | 政策法规 |

### 4.3 空值处理

- 对于无法确定分类的数据，`category`字段可以为空
- 建议定期对空分类数据进行人工审核和标记

## 5. 增量更新要求

### 5.1 新增数据

- 新爬取的数据必须标记分类字段
- 分类标记应在数据入库前完成

### 5.2 历史数据

- 建议对历史数据进行分类标记补全
- 可以采用批量处理方式，逐步完善历史数据的分类信息

## 6. 分类准确性要求

### 6.1 准确率目标

- 基于爬取来源的标记：准确率≥99%
- 基于内容的辅助标记：准确率≥95%
- 整体分类准确率：≥98%

### 6.2 监控机制

- 建立分类准确性监控机制
- 定期抽样检查分类标记的准确性
- 对低准确率的分类规则进行优化

## 7. 异常处理

### 7.1 无法确定分类

- 对于无法确定分类的数据，`category`字段设为空
- 记录日志，便于后续人工处理

### 7.2 分类冲突

- 当多种分类规则匹配时，采用优先级高的分类
- 记录冲突日志，便于优化分类规则

## 8. 爬虫配置要求

### 8.1 分类规则配置

- 支持外部配置分类规则，便于调整和扩展
- 分类规则应包含来源匹配规则和关键词匹配规则
- 支持正则表达式匹配

### 8.2 分类规则更新

- 支持动态更新分类规则，无需重启爬虫
- 分类规则更新后，应重新处理未分类的数据

## 9. 测试要求

### 9.1 分类准确性测试

- 对每个分类进行样本测试，确保准确率达标
- 测试不同来源的数据分类准确性
- 测试不同类型数据的分类准确性

### 9.2 性能测试

- 分类标记不应显著影响爬虫性能
- 分类标记耗时应控制在100ms以内

### 9.3 异常情况测试

- 测试无法确定分类的数据处理
- 测试分类冲突的数据处理
- 测试新增分类的处理

## 10. 维护要求

### 10.1 规则维护

- 定期更新分类规则，适应新的内容形式
- 优化低准确率的分类规则

### 10.2 日志监控

- 记录分类标记的日志，包括分类结果、匹配规则、处理时间等
- 定期分析日志，发现问题并优化

### 10.3 文档更新

- 当分类体系变更时，及时更新相关文档
- 保持爬虫配置与文档的一致性
