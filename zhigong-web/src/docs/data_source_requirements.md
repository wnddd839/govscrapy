# 数据请求要求文档

## 1. 概述

本文档定义了前端各页面的数据请求要求，明确了不同页面应该使用的数据源（Redis/MySQL）以及API调用时需要传递的参数。

## 2. 数据源说明

- **Redis**：用于存储热门推荐、缓存数据，适用于对实时性要求不高但访问频繁的数据
- **MySQL**：用于存储完整的政务信息和岗位数据，适用于需要精确查询、筛选和分页的数据

## 3. 页面数据请求要求

### 3.1 首页 (HomeView.vue)

- **页面路径**：`/`
- **数据源要求**：Redis
- **API调用**：`getHotInfo(region, source)`
- **默认参数**：
  - `source`: `'redis'`
- **功能说明**：获取热门推荐的政务信息

### 3.2 发现页面 (ListView.vue)

- **页面路径**：`/list`
- **数据源要求**：MySQL
- **API调用**：`getInfoList(params)`
- **必填参数**：
  - `source`: `'mysql'`
- **可选参数**：
  - `q`: 搜索关键词
  - `region`: 地区
  - `startDate`: 开始日期
  - `endDate`: 结束日期
  - `page`: 页码（0-based）
  - `size`: 每页条数
- **功能说明**：根据条件搜索和筛选政务信息列表

### 3.3 分类页面 (CategoryView.vue)

- **页面路径**：`/category/:name`
- **数据源要求**：MySQL
- **API调用**：`getInfoList(params)`
- **必填参数**：
  - `source`: `'mysql'`
- **可选参数**：
  - `q`: 搜索关键词
  - `page`: 页码（0-based）
  - `size`: 每页条数
- **功能说明**：根据分类名称获取相关政务信息列表

### 3.4 详情页面 (DetailView.vue)

- **页面路径**：`/detail/:id`
- **数据源要求**：MySQL
- **API调用**：`getInfoDetail(id, source)`
- **必填参数**：
  - `source`: `'mysql'`
- **功能说明**：获取单条政务信息的详细内容

### 3.5 岗位速查页面 (JobListView.vue)

- **页面路径**：`/jobs`
- **数据源要求**：MySQL
- **API调用**：`searchJobs(params)`
- **必填参数**：
  - `source`: `'mysql'`
- **可选参数**：
  - `major`: 专业要求
  - `degree`: 学历要求
  - `q`: 搜索关键词
  - `page`: 页码（0-based）
  - `size`: 每页条数
- **功能说明**：根据条件搜索和筛选岗位信息

## 4. 后端处理逻辑要求

### 4.1 API请求参数处理

后端需要根据请求中传递的`source`参数，决定从哪个数据源获取数据：

- 当`source`为`'redis'`时，从Redis缓存中获取数据
- 当`source`为`'mysql'`时，直接从MySQL数据库中查询数据
- 如果未传递`source`参数，默认使用`'mysql'`作为数据源

### 4.2 API响应格式

所有API响应应保持一致的格式，无论从哪个数据源获取数据：

```json
{
  "data": [...], // 数据列表
  "total": 100,  // 总条数（仅分页接口）
  "page": 0,     // 当前页码（仅分页接口）
  "size": 20     // 每页条数（仅分页接口）
}
```

## 5. 数据更新机制

- **Redis数据**：应该定期从MySQL同步，建议同步频率为每小时一次
- **MySQL数据**：实时更新，确保数据的准确性和完整性

## 6. 注意事项

1. 所有API调用必须传递`source`参数，明确指定数据源
2. 后端需要对`source`参数进行校验，防止无效值
3. 对于Redis中不存在的数据，后端应降级到MySQL获取，并更新Redis缓存
4. 分页查询必须使用MySQL数据源，确保数据的完整性和一致性
5. 搜索和筛选功能必须使用MySQL数据源，确保查询结果的准确性
